# Bedi Cloth House Management System

## Project Overview
The Bedi Cloth House Management System is a Python-based business management application developed using Streamlit and MySQL. It helps manage store data, maintain records, and monitor business activities through an interactive dashboard.

## Technologies Used
- Python
- Streamlit
- MySQL
- Pandas
- Excel

## Main Features
- Interactive business dashboard
- MySQL database integration
- Create, Read, Update and Delete (CRUD) operations
- Business data management
- Data visualisation and reporting
- User-friendly interface

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/kaurrajkom2026-droid/Bedi-Cloth-House-Management-System.git
```

### 2. Open the Project Folder

```bash
cd Bedi-Cloth-House-Management-System
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure MySQL

- Install and start MySQL.
- Create the required database.
- Configure the database connection in `database.py`.
- Run the data import script if required.

### 5. Run the Application

```bash
streamlit run app.py
```
